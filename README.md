# 📊 Customer Churn Dashboard (Power BI Sample Project)

## Overview

This repository contains a **sample Customer Churn Dashboard** created in **Microsoft Power BI** for learning, practice, and portfolio purposes. The dashboard demonstrates how Power BI can be used to transform raw customer data into meaningful business insights through interactive visualizations and KPIs.

The project is intended as a showcase of Power BI dashboard design, data modeling, Power Query transformations, and DAX calculations.

---

## Objectives

* Demonstrate Power BI dashboard development skills.
* Analyze customer churn using interactive visualizations.
* Present business insights through KPIs and charts.
* Showcase Power Query and DAX capabilities.

---

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Dataset

---

## Dashboard Features

* Customer Churn Rate
* Total Customers
* Active vs. Churned Customers
* Customer Demographics
* Contract Type Analysis
* Payment Method Analysis
* Monthly Charges Analysis
* Interactive Filters and Slicers

---

## Purpose

This is a **sample project** created for educational and portfolio purposes. It demonstrates dashboard design and data visualization techniques in Power BI and can serve as a reference for students, beginners, and recruiters interested in Power BI projects.


## Disclaimer

The dataset used in this project is intended for demonstration and learning purposes only. The insights shown are illustrative and should not be interpreted as representing any real organization's customer data.
